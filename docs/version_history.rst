Version history
===============

0.1.1
-----

Date
~~~~
2026-11-09

Description
~~~~~~~~~~~

- Adding Jacobians of array-valued metrics. Adjoint differentiation is now vectorized, and 
  ``metric_name`` can include array quantities, such as ``'phi_dofs'`` for the current 
  potential solution, with a Jacobian for every component.
- Adding memory controls for large problems:

  - ``bs_chunk_size`` processes Biot-Savart evaluation points in chunks in the 
    winding-surface and self-field kernels.
  - ``jac_chunk_size`` differentiates adjoint rows in chunks. This is strongly recommended 
    for array metrics such as ``'phi_dofs'``, because peak memory now grows with one chunk 
    instead of all of them.
  - With chunking off (``None``), the default fully vectorized path is unchanged.

- Caching the field operators that don't depend on phi (the winding-surface B and the 
  self field) once per solve. This speeds up the solve and reduces autodiff memory in 
  ``f_B`` and the force objectives.
- Switching the augmented Lagrangian inner solver from ``optimistix.LBFGS`` to 
  ``optax.lbfgs`` with a zoom line search. The final step sizes (``fin_dx``, ``fin_du``, 
  ``fin_df``) are now reported. ``optax`` is now a dependency.
- Adding ``export_winding_dofs`` to return the winding surface degrees of freedom and 
  their derivatives, mainly for DESC free-boundary workflows.
- Fixing the self magnetic field and simplifying its calculation. Singular integration 
  now lives in the self-field module, and the force can be evaluated on a surface with a 
  different resolution than the winding surface.
- Adding the self-field quantities ``B_self``, ``B_self_cyl``, ``B2_self``, 
  ``B_self_norm``, ``f_B_self``, ``f_max_B2_self`` and ``f_l1_B_self_norm``, and 
  exposing the self-force fields ``force_xyz`` and ``force_cyl`` for ``'<='`` and 
  ``'>='`` constraints.
- Fixing the pseudo-Huber smoothing in ``f_huber_K``.
- Fixing NaNs and inaccuracies in gradients.
- Raising clearer error messages for common failures caused by bad parameter choices.
- Rewriting coil cutting:

  - ``coil_xyz_from_qp`` is replaced by ``gamma_current_from_qp``, which returns 
    ``(gammas, currents)``.
  - Curves are fitted by least squares (``curve_from_gamma``) instead of FFT, so scipy 
    is no longer needed.
  - Adding ``planar_curve_from_gamma`` to fit simsopt's ``CurvePlanarFourier``.

- Adding ``m``/``n`` mode-number properties to the JAX surfaces.
- Moving the example notebooks into a new Examples chapter in the documentation.
- Breaking changes:

  - ``quadcoil.quantity`` and ``quadcoil.solver`` are renamed to ``quadcoil.quantities`` 
    and ``quadcoil.solvers``. The old names still work as aliases.
  - Removing the ``implicit_linear_solver`` argument of ``quadcoil()``.
  - Removing the ``quadcoil.io.quadcoil_desc`` wrapper. The DESC interface now lives in 
    DESC. See :doc:`examples/quasi_single_stage`.
  - Removing the unused ``'svtol'`` option from the ``'auglag-lbfgs'`` solver options.
  - Coil cutting no longer writes coils files.
  - Python 3.11 or newer is required.

Development update
------------------

Date
~~~~
2026-06-22

Description
~~~~~~~~~~~

- Adding xyz surface (``SurfaceXYZFourierJAX``).
- Adding xyz tensor surface (``SurfaceXYZTensorFourierJAX``).
- Adding exact uniform offset surface (``SurfaceOffsetJAX``), produced by calling 
  ``Surface.uniform_offset()`` on any surface that's not a ``SurfaceOffsetJAX``.
- Overhauling winding surface generators to work for all 3 surface types (a 
  ``SurfaceOffsetJAX`` cannot be offset again by design). Improving smoothness. The winding 
  surface can now simply be generated by calling ``Surface.gen_winding_surface()``.
- Changing the signature of ``quadcoil()`` to reflect the updates in winding surface 
  generators.
- Overhauling adjoint differentiation to use the KKT condition, instead of the 
  unconstrained auglag objective.
- Adding preconditioners:

  - ``precond='svd'`` for svd of induction matrix.
  - ``precond='svd_K'`` to use the svd of the r-phi-z current K matrix.
  - ``precond='ess'`` to use exponential spectral scaling.

- Adding ``nescoil()``. It takes largely the same parameters as ``quadcoil()`` but solves 
  the NESCOIL problem.
- Adding the option to initialize a QUADCOIL run from a NESCOIL solution.
- Adding interior point method (``solver='ipm'``) and slsqp-jax solver 
  (``solver='slsqp'``). However, benchmarks show that auglag still works the best.
